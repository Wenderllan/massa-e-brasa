# 🍕 Massa & Brasa

Landing page responsiva desenvolvida para uma pizzaria e esfiharia artesanal fictícia.

O projeto foi criado com foco em uma experiência simples e agradável para o cliente, permitindo visualizar produtos, conhecer o estabelecimento e iniciar pedidos diretamente pelo WhatsApp.

## 🌐 Projeto online

Acesse a versão publicada:

https://wenderllan.github.io/massa-e-brasa/

## 🚀 Funcionalidades

- Layout responsivo para desktop e dispositivos móveis
- Cardápio com pizzas e esfihas
- Seção de combo promocional
- Integração dos produtos com WhatsApp
- Botões gerais para realização de pedidos
- Menu mobile interativo
- Navegação entre as seções da página
- Informações sobre o estabelecimento
- Metadados básicos para SEO e compartilhamento
- Favicon personalizado

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- GitHub Pages

## 📱 Responsividade

O projeto foi desenvolvido para se adaptar a diferentes tamanhos de tela, incluindo smartphones, tablets e computadores.

## 💬 Integração com WhatsApp

Os botões de pedido geram automaticamente uma mensagem com o produto selecionado e direcionam o usuário para o WhatsApp.

> O número de WhatsApp utilizado nesta demonstração é fictício.

## 🎯 Objetivo do projeto

Este projeto foi desenvolvido para praticar e demonstrar conhecimentos de desenvolvimento Front-End, incluindo estruturação HTML, estilização responsiva com CSS, interatividade com JavaScript, versionamento com Git e publicação utilizando GitHub Pages.
